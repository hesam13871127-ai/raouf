## نکات
فرمها بدون بارگذاری مجدد، با جلوگیری از ارسال دوبار، حفظ مقادیر هنگام خطا و پیام موفقیت فقط پس از INSERT قطعی کار میکنند. اگر افزونه غیرفعال شود، قالب به CPT خصوصی fallback میکند و هنگام فعالسازی مجدد مهاجرت انجام میشود.

محیط تست SQLite/Playground است؛ MySQL/MariaDB واقعی، SMTP، multisite، نسخههای دیگر WP/PHP، دستگاههای فیزیکی، افزونههای شخص ثالث، Theme Check، PageSpeed/CDN/تست بار و مهاجرت بین دو هاست **NOT TESTED** هستند.
