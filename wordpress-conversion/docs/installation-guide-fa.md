# راهنمای نصب قالب وردپرس آموزشگاه فنی و حرفه‌ای رئوف

نسخه ۱.۰.۰ — تبدیل دقیق وب‌سایت HTML/CSS/JS به قالب استاندارد وردپرس، بدون هیچ تغییر بصری.

## ۱. پیشنیازها

| مورد | حداقل | نسخه تستشده |
| --- | --- | --- |
| وردپرس | 6.4 | 6.8.3 |
| PHP | 8.0 | 8.3.36 |
| پایگاه داده | MySQL / MariaDB | SQLite (Playground) |
| `upload_max_filesize` / `post_max_size` | ≥ 8MB (توصیه 16M) | 64M |
| پیوندهای یکتا | غیر از «ساده» | `/%postname%/` |
| افزونه اجباری | هیچکدام | — |

قالب به هیچ صفحهساز، المنتور، ووکامرس، jQuery یا کتابخانه خارجی نیاز ندارد. تمام فونت‌ها، تصاویر، آیکون‌ها، CSS و JavaScript به‌صورت محلی در بسته قرار دارند.

## ۲. فایل تحویلی

`raouf-academy-wordpress-theme.zip` (حدود ۵.۱۳ مگابایت). در ریشه ZIP تنها پوشه `raouf-academy/` وجود دارد؛ هیچ فایل توسعهای اضافهای نیست. سلامت ZIP با `unzip -t` بررسی شده است.

## ۳. نصب از طریق پیشخوان (توصیهشده)

1. وارد پیشخوان وردپرس شوید.
2. **نمایش ← پوسته‌ها ← افزودن پوسته تازه ← بارگذاری پوسته** (`Appearance → Themes → Add New → Upload Theme`).
3. فایل ZIP را انتخاب و **هماکنون نصب کن** را بزنید.
4. پس از پیام «Theme installed successfully»، **فعال کردن** را بزنید.
5. صفحه نخست را باز کنید؛ همان ظاهر منبع اصلی نمایش داده می‌شود.

> **تست شده:** این مسیر دقیقاً روی یک نصب تازه وردپرس ۶.۸.۳ اجرا و ۲۴/۲۴ گام آن، شامل ۱۱/۱۱ مسیر و منوهای واقعی، تأیید شد. بستهٔ تحویلی همان ZIP آزمودهشده است.

اگر محدودیت آپلود سرور کمتر از اندازه فایل است، `upload_max_filesize` و `post_max_size` را به `16M` افزایش دهید یا پوشه `raouf-academy/` را با FTP در `wp-content/themes/` قرار دهید و از **نمایش ← پوسته‌ها** فعال کنید.

## ۴. کارهای خودکار هنگام فعالسازی

- ایجاد **ده صفحه وردپرس** (خانه، دوره‌ها، چهار دوره، درباره، گالری، تماس، ثبتنام) با `post_content` دقیقاً برابر HTML منبع و قابل ویرایش.
- تنظیم صفحه نخست ایستا روی صفحه خانه و پیوندهای یکتا روی `/%postname%/`.
- ایجاد و تخصیص دو منوی واقعی: **منوی اصلی رئوف (هدر و موبایل)** و **منوی دوره‌های آموزشی (فوتی)**.
- ثبت نوع نوشته خصوصی `raouf_submission` برای ذخیره امن درخواست‌ها.

صفحات و منو‌ها فقط در صورت نبودن ساخته می‌شوند. برای بازسازی: **نمایش ← تنظیمات قالب رئوف ← همگامسازی صفحات**.

## ۵. ویرایش محتوا بدون دستکاری PHP

| بخش | محل ویرایش |
| --- | --- |
| متن و تصاویر صفحات | **صفحات ← ویرایش** |
| منوی هدر، موبایل و فوتی | **نمایش ← منو‌ها** |
| نام سایت، تلفن، نشانی، اینستاگرام، ایمیل مدیر | **نمایش ← تنظیمات قالب رئوف** |
| جایگزینی تکتک تصاویر | **نمایش ← تنظیمات قالب رئوف ← تصاویر** |
| مشاهده درخواست‌ها | **نمایش ← درخواست‌های ثبت‌شده** |

## ۶. فرم‌ها

`app.js` بدون تغییر به `/api/registrations` و `/api/contact` ارسال می‌کند. سمت سرور: nonce وردپرس + CSRF دوبارارسال، پاکسازی و اعتبارسنجی (شامل ارقام فارسی)، honeypot، محدودیت ۸ درخواست در ۱۵ دقیقه، جلوگیری از تکرار، ذخیره واقعی در `raouf_submission` پیش از پاسخ `201`، و در صورت تنظیم ایمیل مدیر، `wp_mail()`. پیام موفقیت فقط پس از ذخیره موفق نمایش داده می‌شود.

> ارسال ایمیل SMTP در محیط تست **NOT TESTED** است (بدون سرور ایمیل). ذخیره و نمایش در پیشخوان تست و تأیید شده است.

## ۷. نکات فنی و عیبیابی

- استایل‌های بلوک/سراسری، ایموجی، oEmbed، speculation rules، نوار مدیر نمای سایت و shortlink هسته حذف شده‌اند تا CSS منبع بدون رقیب بماند.
- هر صفحه دقیقاً یک `style.css` و یک `app.js` با `defer` بارگذاری می‌کند.
- سه فونت WOFF2 محلی Vazirmatn؛ فقط مسیر `@font-face` از مطلق به نسبی تغییر کرده است.
- خطای ۴۰۴ پس از نصب: **تنظیمات ← پیوندهای یکتا ← ذخیره تغییرات**.
- فونت/تصویر بارگذاری نمی‌شود: از انتقال کامل `assets/` و مجوزهای خواندن اطمینان حاصل کنید.
- متندامین `raouf-academy` و فایل `languages/raouf-academy.pot`.
